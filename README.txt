Our Little Study Garden - PWA

HOW TO PUT IT ONLINE (free, 2 minutes). The camera only works on https, so it has to be hosted:
  Netlify:  go to app.netlify.com/drop and drag this whole folder onto the page.
  or GitHub Pages / Cloudflare Pages: upload these files to a new site.

HOW TO INSTALL ON YOUR PHONE
  Android (Chrome): open the link, menu, "Install app" / "Add to Home screen".
  iPhone (Safari): open the link, Share, "Add to Home Screen".

Notes
  - Your notes, letters and photos are saved inside the browser on each device. Open the site in the same
    browser/app each time. A new address starts with an empty garden (use Export/Import to move things).
  - If you change the address, the saved data does not follow it.
